# Визуализация 04: WS2813 RGB LED Stick

Проверка Seeed Grove RGB LED Stick с десятью WS2813 Mini. Демо-режим RPM
использует общий цикл Визуализации 03: `3000 → 7000 → 3000`, шаг 100 RPM
каждые 75 мс и пауза на максимуме около 1,5 секунды.

Стик подключается в Grove-порт AtomS3R: белый провод `SIG` — G1, чёрный —
GND, красный — питание; жёлтый провод `NC` не используется. Эта распиновка
проверена на подключённом стике. Работа также проверена с Grove-кабелем 2 м.
Atomic CAN Base в этой визуализации может оставаться подключённым: демо-режим
не использует CAN и формирует обороты самостоятельно.

| LED | Цвет | RPM |
| ---: | --- | ---: |
| 1 | Зелёный | 4300 |
| 2 | Зелёный | 4500 |
| 3 | Зелёный | 4700 |
| 4 | Зелёный | 4900 |
| 5 | Зелёный | 5100 |
| 6 | Жёлтый | 5300 |
| 7 | Жёлтый | 5500 |
| 8 | Жёлтый | 5700 |
| 9 | Красный | 5900 |
| 10 | Красный | 6100 |

При достижении каждой точки загорается соответствующий LED. Первый LED —
ближайший к входному разъёму стика.
С 6300 RPM и до конца демо-диапазона все десять диодов постоянно горят красным.
Яркость установлена на `32/255` вместо прежних `64/255`.
