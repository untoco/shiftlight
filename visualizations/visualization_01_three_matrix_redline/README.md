# Визуализация 01: три матрицы и redline

Проверка индикации shiftlight на первых трёх матрицах Chain RGB, соединённых
последовательно `AtomS3R → #1 → #2 → #3`. CAN в этом тесте не используется и
никакие кадры в автомобильную сеть не передаются.

## Логика

- На экране AtomS3R крупно отображается тестовый RPM: `3000 → 7000 → 3000`.
  Шаг — 100 RPM каждые 75 мс.
- На общей полосе 24×8 пикселей расположены пять секций 3×3 с зазором 2
  пикселя. Они начинаются на позициях `0`, `5`, `10`, `15`, `20`.
- Пороги используются из общего конфига: 4500, 5100, 5700, 6300 и 6500 RPM.
  Первые три секции зелёные, последующие — жёлтые.
- С 6300 RPM все пять секций становятся красными.
- С 6500 RPM все три матрицы
  мигают красным с фазами 150 мс. Для уменьшения рассинхрона красный кадр
  загружается один раз, затем переключается только яркость матриц.

Число RPM на экране AtomS3R автоматически масштабируется до максимально
возможной ширины дисплея.

Прошить тест можно обычной командой из корня репозитория:

```bash
.tooling/platformio/bin/pio run --target upload --upload-port /dev/cu.usbmodem101
```
