# Визуализация 03: нижняя половина матриц

Проверка видимости shiftlight за рулём. Используются те же три матрицы, карта
RPM и цвета, что в Визуализации 02, но скруглённые секции 4×4 перенесены вниз каждой
матрицы: `x=2–5`, `y=4–7`.

Логика RPM:

| Точка | RPM | Индикация |
| ---: | ---: | --- |
| 1 | 4500 | Правая нижняя секция зелёная. |
| 2 | 5100 | Правая и центральная нижние секции зелёные. |
| 3 | 5700 | Левая нижняя секция жёлтая, остальные зелёные. |
| 4 | 6300 | Все три нижние секции красные. |
| 5 | 6500 | Нижние 4 пикселя всех матриц мигают красным. |

Демо-режим: 3000–7000 RPM, шаг 100 RPM каждые 75 мс, пауза на 7000 RPM — около 1,5 секунды.

## Прежняя основная прошивка с матрицами

Каталог [`can`](can) содержит прежний вариант основной прошивки: приём RPM из
PT-CAN, вывод на три Chain RGB и стартовый финишный флаг. Его матричные
параметры сохранены в [`matrix_config.h`](matrix_config.h). Этот код оставлен
для возвращения к матрицам; актуальная основная прошивка использует LED Stick.

Для сборки архивного варианта временно укажите в корневом `platformio.ini`
`src_dir = visualizations/visualization_03_lower_matrix_blocks/can`.
Для демо матриц укажите `src_dir = visualizations/visualization_03_lower_matrix_blocks/src`.
