# PT-CAN: сигнал оборотов двигателя

Источник — предоставленные конфигурация Racebox и CAN-лог. Параметры из
конфигурации подтверждены кадрами в логе.

| Параметр | Значение |
| --- | --- |
| Шина | CAN1, 500 кбит/с, стандартные 11-битные ID |
| CAN ID | `0x0A5` |
| Данные | байт 5 — младший, байт 6 — старший |
| Тип | `uint16`, little-endian |
| Формула | `RPM = raw × 0.25` |
| Наблюдаемая частота | 47.9 Гц в предоставленном логе |

Например, первый кадр `0x0A5` в логе содержит байты
`E5 F2 43 08 84 58 0D F2`. Из байтов 5–6 получается `0x0D58 = 3416`, то есть
`854 RPM`.

В логе найдено 4429 кадров `0x0A5`: значения RPM от 703 до 3740. Поэтому
сигнал, его порядок байтов и коэффициент подтверждены, но точки shiftlight
выше 3800 RPM этим фрагментом не покрываются. Карта порогов по-прежнему
зафиксирована из Test 02 и должна быть откалибрована на автомобиле.

Основная прошивка использует режим `listen-only` и не передаёт или подтверждает
кадры. Если кадры RPM не приходят более 200 мс, матрицы гасятся, а экран
показывает `WAITING FOR RPM`.
