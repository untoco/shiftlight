# BMW PT-CAN Shiftlight

Основная версия shiftlight для BMW использует AtomS3R, Atomic CAN Base и одну
линейку Seeed Grove RGB LED Stick (10 × WS2813 Mini). Контроллер пассивно читает
RPM из PT-CAN, показывает обороты на встроенном экране и управляет десятью
светодиодами. Три матрицы Chain RGB сохранены в
[`Визуализации 03`](visualizations/visualization_03_lower_matrix_blocks) как
предыдущий вариант устройства.

```text
BMW PT-CAN ── CAN H/L ── Atomic CAN Base ── AtomS3R
                                             │ USB-C: питание и прошивка
                                             └─ Grove, G1 (белый SIG) ── кабель 2 м ── RGB LED Stick
```

## Компоненты и подключение

| Количество | Компонент | Назначение |
| ---: | --- | --- |
| 1 | M5Stack AtomS3R | Контроллер ESP32-S3 и экран RPM. |
| 1 | M5Stack Atomic CAN Base (CA-IS3050G) | Подключение к PT-CAN, приём без передачи кадров. |
| 1 | Seeed Grove RGB LED Stick (10 × WS2813 Mini) | Линейный shiftlight. |
| 1 | Grove-кабель 2 м | Соединяет стик с портом AtomS3R; работа с этой длиной проверена. |

Atomic CAN Base использует G5/G6 контроллера. Стик подключается к штатному
Grove-порту AtomS3R: белый провод `SIG` — G1, чёрный — GND, красный — питание,
жёлтый `NC` не используется. Эта распиновка проверена на имеющемся стике.

## Индикация RPM

Каждый достигнутый порог включает соответствующий диод и оставляет включёнными
предыдущие. Нумерация идёт от входного разъёма стика.

| Диод | Цвет | Порог RPM |
| ---: | --- | ---: |
| 1 | Зелёный | 4300 |
| 2 | Зелёный | 4500 |
| 3 | Зелёный | 4700 |
| 4 | Зелёный | 4900 |
| 5 | Зелёный | 5100 |
| 6 | Жёлтый | 5300 |
| 7 | Жёлтый | 5500 |
| 8 | Жёлтый | 5700 |
| 9 | Красный | 5900 |
| 10 | Красный | 6100 |

С 6300 RPM все десять диодов постоянно горят красным. Яркость — `32/255`.
Пороги и цветовые настройки находятся в
[`include/shiftlight_config.h`](include/shiftlight_config.h).

### Тест панели при запуске двигателя

После обнаружения запуска двигателя две оранжевые точки идут от крайних
диодов к центру и обратно. Используется тёмный тёплый оттенок `#C03800`;
анимация длится около секунды. При включении питания S3R она сама по себе не
запускается.

Прошивка запускает тест один раз при переходе от остановки или прокрутки
стартера к устойчивым оборотам: RPM не выше 100 в течение 1 с либо
наблюдаемая прокрутка 101–399 RPM в течение 100 мс, затем RPM от 400 в
течение 150 мс.
Если S3R включён при уже работающем двигателе, тест пропускается. При потере
RPM более 2 с состояние запуска сбрасывается; новые обороты в зоне прокрутки
снова позволяют распознать запуск. Эти границы предварительные и проверяются
на автомобиле. Во время анимации CAN продолжает обрабатываться; появление
оборотов зоны shiftlight или потеря RPM немедленно прекращает тест.

### CAN и экран

| Параметр | Значение |
| --- | --- |
| Шина | PT-CAN, 500 кбит/с, только приём (`listen-only`) |
| CAN ID оборотов | `0x0A5`, стандартный 11-битный кадр |
| Кодирование | байт 5 — младший, байт 6 — старший; `uint16`, little-endian |
| Формула | `RPM = raw × 0.25` |

При отсутствии свежего кадра RPM более 200 мс стик гаснет, а экран показывает
`WAITING FOR CAN`. Когда кадры поступают, экран показывает RPM и число
включённых диодов либо `ALL RED`.

## Сборка и прошивка

На Mac нужны Git и Python 3; Arduino IDE и M5Burner не требуются. Если Git
отсутствует, выполните `xcode-select --install`.

```bash
git clone https://github.com/untoco/shiftlight.git
cd shiftlight
python3 -m venv .tooling/platformio
.tooling/platformio/bin/python -m pip install --upgrade pip "platformio==6.1.19"
.tooling/platformio/bin/pio run
```

Для загрузки подключите AtomS3R к Mac через USB-C и найдите его порт:

```bash
.tooling/platformio/bin/pio device list
.tooling/platformio/bin/pio run --target upload --upload-port /dev/cu.usbmodem101
```

Замените `/dev/cu.usbmodem101` на порт из списка. По умолчанию собирается
основная CAN-прошивка из [`src/main.cpp`](src/main.cpp). Демо-оборотами она не
пользуется.
