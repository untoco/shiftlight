# Тест 02: три центральные секции

Проверка той же связки `AtomS3R + Atomic CAN Base + 3 Chain RGB`. CAN в тесте
не используется. Каждая матрица содержит одну секцию 4×4 в центре, по
координатам `x=2–5`, `y=2–5`. Угловые пиксели секции светятся примерно вчетверо слабее
основного цвета, создавая визуально скруглённую форму. Это не применяется к
полной красной заливке redline.

## Логика RPM

| Точка | RPM | Индикация |
| ---: | ---: | --- |
| 1 | 3800 | Правая центральная секция зелёная. |
| 2 | 4400 | Правая и центральная секции зелёные. |
| 3 | 5000 | Правая и центральная секции зелёные, левая жёлтая. |
| 4 | 5600 | Все три центральные секции красные. |
| 5 | 6200 | Все три матрицы мигают красным. |

RPM в тесте циклически меняется от 3000 до 7000 с шагом 100 RPM каждые 75 мс.
На 7000 RPM значение удерживается около 1,5 секунд. Начиная с 6200 RPM
матрицы продолжают мигать красным. Для синхронного мигания
полный красный кадр загружается один раз, а дальше переключается только
яркость матриц с фазой 150 мс.

На четвёртой точке в шину передаются только 16 пикселей центральной секции
каждой матрицы, а не весь кадр 8×8. Одинаковые кадры между точками RPM не
повторяются: это уменьшает задержку последовательного закрашивания матриц.

Число RPM на экране AtomS3R автоматически масштабируется до максимально
возможной ширины дисплея.
