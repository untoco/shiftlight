# Тест 02: три центральные секции

Проверка той же связки `AtomS3R + Atomic CAN Base + 3 Chain RGB`. CAN в тесте
не используется. Каждая матрица содержит одну секцию 4×4 в центре, по
координатам `x=2–5`, `y=2–5`.

## Логика RPM

| Точка | RPM | Индикация |
| ---: | ---: | --- |
| 1 | 3800 | Первая центральная секция зелёная. |
| 2 | 4400 | Первая и вторая секции зелёные. |
| 3 | 5000 | Первые две секции зелёные, третья жёлтая. |
| 4 | 5600 | Все три центральные секции красные. |
| 5 | 6200 | Все три матрицы мигают красным. |

RPM в тесте циклически меняется от 3000 до 6200 с шагом 100 RPM каждые 75 мс.
На 6200 RPM значение удерживается около 1,5 секунд. Для синхронного мигания
полный красный кадр загружается один раз, а дальше переключается только
яркость матриц с фазой 150 мс.
