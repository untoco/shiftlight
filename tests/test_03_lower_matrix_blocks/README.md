# Test 03: нижняя половина матриц

Проверка видимости shiftlight за рулём. Используются те же три матрицы, карта
RPM и цвета, что в Test 02, но скруглённые секции 4×4 перенесены вниз каждой
матрицы: `x=2–5`, `y=4–7`.

Логика RPM:

| Точка | RPM | Индикация |
| ---: | ---: | --- |
| 1 | 3800 | Правая нижняя секция зелёная. |
| 2 | 4400 | Правая и центральная нижние секции зелёные. |
| 3 | 5000 | Левая нижняя секция жёлтая, остальные зелёные. |
| 4 | 5600 | Все три нижние секции красные. |
| 5 | 6200 | Все матрицы мигают красным. |

Тестовый диапазон: 3000–7000 RPM.
