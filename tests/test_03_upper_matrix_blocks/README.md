# Test 03: верхняя половина матриц

Проверка видимости shiftlight за рулём. Используются те же три матрицы, карта
RPM и цвета, что в Test 02, но скруглённые секции 4×4 перенесены вверх каждой
матрицы: `x=2–5`, `y=0–3`.

Логика RPM:

| Точка | RPM | Индикация |
| ---: | ---: | --- |
| 1 | 3800 | Правая верхняя секция зелёная. |
| 2 | 4400 | Правая и центральная верхние секции зелёные. |
| 3 | 5000 | Левая верхняя секция жёлтая, остальные зелёные. |
| 4 | 5600 | Все три верхние секции красные. |
| 5 | 6200 | Все матрицы мигают красным. |

Тестовый диапазон: 3000–7000 RPM.
